
# Smart Grocery System

## Project Overview
Smart Grocery System is a grocery management application designed to demonstrate CI/CD automation.

## Technologies Used
- Python
- GitHub Actions
- flake8
- nose
- Tekton
- OpenShift
- Buildah

## Project Objective
To implement Continuous Integration and Continuous Deployment using GitHub Actions, Tekton Pipelines, and OpenShift.

## CI/CD Pipeline Features
1. Source code management using GitHub.
2. Code linting using flake8.
3. Automated unit testing using nose.
4. Container image building using Buildah.
5. Application deployment using OpenShift.

## Conclusion
This project demonstrates an automated software development and deployment workflow using DevOps tools.
